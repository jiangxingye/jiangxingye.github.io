ubuntu系统下安装cuda和cudnn驱动方法

ubuntu系统下安装cuda和cudnn驱动方法
2019-09-17 · 1 min · 209 words · jiangxingye

Ubuntu 16.04 系统下安装 cuda 驱动方法一、cuda install cuda 包含nvidia 显卡驱动 ，如果事先安装好了 nvidia 显卡驱动，在安装 cuda的时候提示安装 nvidia 显卡驱动时候选择 no，不用安装显卡驱动。

cuda 下载链接：https://developer.nvidia.com/cuda-toolkit cuda 安装前准备 二、禁用 ubuntu 系统自带的nvidia 第三方驱动：nouveau禁用方法：

编译/etc/modprobe.d/blacklist.conf nano /etc/modprobe.d/blacklist.conf 在配置文件的最后一页贴加如下命令。

blacklist nouveau options nouveau modeset=0 贴加完毕后按ctrl+x 保存 选 y 保存，然后回车即可退出编译界面。

执行命令加载文件：

update-initramfs –u 重启机器 执行：lsmod | grep nouveau 命令，如果屏幕没有输出，说明禁用nouveau 成功。

三、禁用 X-Window 服务首先用命令：service lightdm stop 禁用图形界面 然后用命令 Ctrl-Alt+F1 进入命令行界面，输入用户名和密码登录 安装 cuda 把 cuda 驱动拷贝到根目录下， 然后进入到根目录下面， 记住要 root 权限安装 。用命令:./cuda.xxx.run -no-opengl-libs 安装 进入安装界面，首先阅读安装说明，可以用 ctrl+c 跳过，也可以用空格一个个的看完。一般直接忽略。

进入安装，第一个问题:选择接受 accept，第二个问题:问是否安装 nvidia显卡驱动？

如果事前安装了驱动，可以选择 no，不然后就选者 yes。然后第三个问题及后面的问题都选择 yes。没有 yes/no 选择的用回车默认就可以了。

Cuda 安装完毕。

四、设置环境变量：终端中输入 ：sudo gedit /etc/profile 在打开的文件末尾，添加以下两行。

export PATH=/usr/local/cuda-10.1/bin:$PATH export LD_LIBRARY_PATH=/usr/local/cuda-10.1/lib64:$LD_LIBRARY_PATH保存文件，并重启。因为 source /etc/profile是临时生效，重启电脑才是永久生效。

五、重启电脑，检查上述的环境变量是否设置成功 a、 验证驱动版本敲入 $ cat /proc/driver/nvidia/version 结果显示 NVRM version:

NVIDIA UNIX x86_64 Kernel Module 384.81 Sat Sep 2 02:43:11 PDT 2017 GCC version:

gcc version 5.4.0 20160609 (Ubuntu 5.4.0-6ubuntu1~16.04.5)b、 验证 CUDA Toolkit 敲入 $ nvcc -V 会输出 CUDA 版本信息 如果是这样的：

The program ‘nvcc’ is currently not installed. You can install it by typing:sudo apt-get install nvidia-cuda-toolkit。

可能是环境配置没有成功，请重复上述步骤 7 测试 CUDA 的 Samples 例子 运行下面命令：

cd /usr/local/cuda-9.0/samples/1_Utilities/deviceQuery make./deviceQuery cd /usr/local/cuda-9.0/samples/1_Utilities/bandwidthTest Make ./ bandwidthTest测试成功会显示结果：pass 六、Cuda 安装成功。

Cuda 安装参考文档及一些常用问题参考此链接：

http://blog.csdn.net/qlulibin/article/details/78714596 cuda 安装完后，安装 cudnn 先去 nvidia 官网下载 cudnn，cudnn下载需要注册账号才能安登陆进去下载。网站：https://developer.nvidia.com/cudnn 先登录，然后同意下载，然后选择自己需要 cudnn 下载 点击下载 tar 的压缩包，然厚把压缩包拷贝到系统下，然后进入到对应目录 执行下面命令，开始安装。

tar -zxvf cudnn-7.5-linux-x64-v5.0-ga.tgz > cp cuda/include/cudnn.h /usr/local/cuda/include/ cp cuda/lib64/libcudnn* > /usr/local/cuda/lib64/ chmod a+r /usr/local/cuda/include/cudnn.h chmod a+r > /usr/local/cuda/lib64/libcudnn* Cudnn 安装完毕。

备注：cudnn 的版本需要和 cuda 的版本是要在兼容范围内，若果不兼容，会报错的。
