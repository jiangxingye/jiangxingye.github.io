ubuntu系统下安装cuda和cudnn驱动方法

Ubuntu 16.04 系统下安装 cuda 驱动方法一、cuda install cuda 包含nvidia 显卡驱动 ，如果事先安装好了 nvidia 显卡驱动，在安装 cuda的时候提示安装 nvidia 显卡驱动时候选择 no，不用安装显卡驱动。 cuda 下载链接：https://developer.nvidia.com/cuda-toolkit cuda 安装前准备 二、禁用 ubuntu 系统自带的nvidia 第三方驱动：nouveau禁用方法： 编译/etc/modprobe.d/blacklist.conf nano /etc/modprobe.d/blacklist.conf 在配置文件的最后一页贴加如下命令。 blacklist nouveau options nouveau modeset=0 贴加完毕后按ctrl+x 保存 选 y 保存，然后回车即可退出编译界面。 执行命令加载文件： update-initramfs –u 重启机器 执行：lsmod | grep nouveau 命令，如果屏幕没有输出，说明禁用nouveau 成功。 三、禁用 X-Window 服务首先用命令：service lightdm stop 禁用图形界面 然后用命令 Ctrl-Alt+F1 进入命令行界面，输入用户名和密码登录 安装 cuda 把 cuda 驱动拷贝到根目录下， 然后进入到根目录下面， 记住要 root 权限安装 。用命令:./cuda.xxx.run -no-opengl-libs 安装 进入安装界面，首先阅读安装说明，可以用 ctrl+c 跳过，也可以用空格一个个的看完。一般直接忽略。 ...
