前言本文将介绍在SpringMVC+Spring+Mybatis项目中添加 dubbo 作为 rpc 服务。 文末有项目代码地址。 一.搭建zookeeper使用 docker 一句话创建： docker run -dit –name zookeeper –hostname zookeeper-host -v /data:/data -p 2181:2181 jplock/zookeeper:latest 二.安装zkui（非必须）这个项目为 zookeeper 提供一个 web 的管理界面。当然我们也可以直接在zookeeper中使用命令查看，所以此步骤可以忽略 在开始前需要安装 Java 环境、Maven 环境。 到 zkui 的项目中下载代码。git clone https://github.com/DeemOpen/zkui.git 执行 mvn clean install 生成jar文件。 将config.cfg复制到上一步生成的jar文件所在目录，然后修改配置文件中的zookeeper地址。 执行 nohup java -jar zkui-2.0-SNAPSHOT-jar-with-dependencies.jar & 测试 http://localhost:9090，如果能看到如下页面，表示安装成功。 三.使用dubbo 在原来 SpringMVC+Spring+Mybatis 项目中，除了原来 spring 相关依赖外，还需要加入以下依赖 com.alibaba dubbo 2.5.5 org.apache.zookeeper zookeeper 3.4.9 com.101tec zkclient 0.2 定义服务接口 public interface IPersonService { List listAll(); ...
